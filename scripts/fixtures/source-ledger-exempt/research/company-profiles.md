# Company profiles — example product

The per-row ledger the log's header declares exempt. Two rows stand in for the
hundred-and-a-half a real profile table carries; neither URL is in the global
log, and that is deliberate rather than a defect. Without the declared
exemption this file alone would report every row as a failure, which is how a
check gets switched off — and switching it off takes the working half with it.
