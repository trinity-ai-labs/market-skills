# Sizing — example product

The file next to the exempt one, which is what says the exemption is scoped to
a file rather than switching the mode off. Its first row is flattened into the
global log and passes; its second names a source with no public address at all.

| S | Source | URL |
|---|---|---|
| S1 | Regulator, deadline notice | https://example.org/deadline |
| S2 | Operator interview, held in the vault | — |

A row with no URL is neither resolved nor failed: there is no key to match it
on. It is counted and named in the success line instead, so a table of
unlinkable rows cannot read as a table that agreed.
